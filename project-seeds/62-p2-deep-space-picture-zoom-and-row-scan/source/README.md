# Reproduce the deep-space scan

Use Node20 or later and the converter's pinned dependencies. Run from the
repository root on Windows, macOS or Linux:

```sh
npm ci --prefix converter
node project-seeds/62-p2-deep-space-picture-zoom-and-row-scan/source/generate.mjs build/space-scan
node converter/odrig.js pack --show shows/space-scan/show.json --mapping mapping/legs-20.json --sources build/space-scan --out build/space-scan/show
node converter/odrig.js check build/space-scan/show/space-scan.odrg
```

Create `build/` first if absent. Choose a fresh output directory; the generator
refuses an existing one and never clears it. `pack` uses the existing encoder
and assembles the demonstration show in one operation. To encode only the
animation, the equivalent command is:

```sh
node converter/odrig.js encode build/space-scan/space-scan.json build/space-scan/space-scan.odrg
```

The generated JSON is about461MB and stays under build/. It is streamed by
the generator; the existing converter subsequently reads it during encoding.
The final compressed animation is34,410,601bytes, below the collection's50MB
limit, and is tracked as
`collection/card/space/space-scan-10x.odrg`. It exceeds the usual internal
animation storage capacity: use SD for physical installation.

The [artifact manifest](artifact.json) records actual input/output checksums,
the generator revision and the final key. The tracked demonstration show uses
brightness40 and repeat1, with no max_seconds; its whole loop is720.16seconds.
The source is already at10x linear zoom from the first frame. It covers ten
alternating rows, nine descents and an additional final bottom-row rightward
pass. Positions are1080x1080 image coordinates, not LED coordinates.

Horizontal passes last60seconds, descents6.68seconds; frames last40ms, with
the exact bottom-right crop held for the final40ms. Pixel-centre bilinear
sampling preserves encoded RGB and reverses rows once for LED storage.

Open [the review page](review/review.html) locally. Its complete-route GIF is
accelerated and sampled, including every segment vertex and the final crop.
Its real-speed GIF shows the first five seconds. Both use the converter's GIF
encoder with the same rendered pictures. They are separate from the normal
24-picture app preview generated by:

```sh
node converter/odrig.js thumbnail collection/card/space/space-scan-10x.odrg --catalog thumbnails --card collection/card --beside
```

Run discovered checks with `npm test --prefix converter`; the route tests use
asymmetric synthetic pixels, while the content test reads the actual binary
through its entire loop and compares independently named camera positions.
After building the shared core, reproduce its complete-loop proof with Python3.10
or later:

```sh
python core/build.py shared
python project-seeds/62-p2-deep-space-picture-zoom-and-row-scan/source/verify.py build/space-scan/show build/space-scan/emulator-proof
```

The proof uses the actual emulator host, shared core and recording writer.
It observes startup readiness before choosing its playback origin, records all
36,012refreshes through the full loop and restart, and compares57selected
LED pictures with the converter's independent decoder, including brightness40
and the target wiring. The recording stays under build/. The emulator fixture
uses64MiB of simulated storage to hold the full animation; this is not a claim
that the board has room for it internally. Use SD on the physical installation.

Emulator proof and remaining human checks are recorded in the specification's
verification document. No physical playback is implied by these review files.
